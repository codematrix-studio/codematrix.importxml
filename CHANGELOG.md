# История изменений

Все заметные изменения проекта фиксируются в этом файле.

## 0.1.0 — начальный перенос CodeMatrix (в разработке)

- Перенесены 430 файлов рабочей части исходного модуля; исторический каталог снимков `source/` исключён из дистрибутива.
- Идентификатор модуля заменён на `codematrix.importxml`.
- Обновлены пространства имён, имена классов, языковые ключи и пути ресурсов.
- Убрана проверка демо-режима из публичной точки входа импортёра.
- Короткие PHP-теги заменены на полные; вызов удалённой в PHP 8 функции `each()` заменён на работу с указателем массива.
- Добавлена GitHub Actions проверка синтаксиса на PHP 8.0–8.4; проверка проходит.
- Удалено остаточное упоминание прежнего партнёра из русской локализации установщика.
- В документации отмечены оставшиеся внешние зависимости: проверка демо/лицензии, OAuth callback Google Drive и ссылки на документацию исходного решения.
- Добавлена русскоязычная документация по переносу и совместимости.

Функциональная проверка в реальном окружении 1С-Битрикс, установка/удаление и регрессионные сценарии импорта ещё не завершены.
