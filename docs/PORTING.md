# План переноса на CodeMatrix

## Цель

Подготовить самостоятельный модуль `codematrix.importxml` для 1С-Битрикс на основе исходного репозитория `ASDAFF/kit.importxml`.

Перенос должен сохранять прикладное поведение импортёра, но использовать собственные идентификаторы CodeMatrix и проверенную совместимость с PHP 8.

## Что необходимо перенести

- административные страницы и меню;
- установщик и деинсталлятор;
- языковые файлы;
- классы и служебные библиотеки модуля;
- JavaScript, CSS, изображения и прочие ресурсы интерфейса;
- обработчики событий, cron-скрипты и интеграционные точки;
- настройки, профили импорта, журналы и механизмы отката.

Исторические снимки исходного кода и каталоги разработки не должны автоматически попадать в дистрибутив. Их назначение необходимо определить отдельно.

## Матрица переименования

| Исходный идентификатор | Целевой идентификатор |
| --- | --- |
| `kit.importxml` | `codematrix.importxml` |
| `kit_importxml` | `codematrix_importxml` |
| `CKitImportXMLRunner` | `CCodeMatrixImportXMLRunner` |
| `Bitrix\\KitImportxml` | `Bitrix\\CodeMatrixImportxml` |
| `KIT_` в собственных языковых ключах | `CODEMATRIX_` |

Переименование выполняется только после проверки всех точек входа и ссылок на классы. Внешние API, форматы данных и идентификаторы сторонних библиотек не переименовываются без технической необходимости.

## Обязательные проверки

1. Все пути в установщике соответствуют новому ID модуля.
2. Файлы административной части копируются в правильные имена и подключают целевой модуль.
3. Автозагрузка регистрирует все классы и корректные пространства имён.
4. Меню, языковые файлы и административные ресурсы используют новые ключи.
5. События, cron и пользовательские точки входа используют новый ID.
6. Установка и удаление не затрагивают файлы других модулей.
7. Существующие профили и настройки не теряются при обновлении.
8. В репозитории нет ссылок на старые собственные идентификаторы, кроме документации истории переноса и явно оговорённых совместимых миграций.

## Лицензии и авторские уведомления

Удаляются только собственные рекламные, брендовые и копирайтные упоминания, на удаление которых у проекта есть права. Уведомления об авторстве, лицензиях и условиях распространения сторонних библиотек, а также обязательные заголовки исходных компонентов сохраняются. Перед включением стороннего кода в релиз проверяется его лицензия.
