# План переноса на CodeMatrix

## Цель

Подготовить модуль `codematrix.importxml` для 1С-Битрикс на основе исходного репозитория `ASDAFF/kit.importxml`.

Перенос должен сохранять прикладное поведение импортёра, использовать идентификаторы CodeMatrix и не нарушать авторские права и лицензии исходных компонентов.

## Матрица переименования

| Исходный идентификатор | Целевой идентификатор |
| --- | --- |
| `kit.importxml` | `codematrix.importxml` |
| `kit_importxml` | `codematrix_importxml` |
| `CKitImportXMLRunner` | `CCodeMatrixImportXMLRunner` |
| `Bitrix\\KitImportxml` | `Bitrix\\CodeMatrixImportxml` |
| `KIT_` в собственных языковых ключах | `CODEMATRIX_` |

Внешние API, форматы данных и идентификаторы сторонних библиотек не переименовываются без технической необходимости.

## Обязательные проверки

1. Все пути в установщике соответствуют новому ID модуля.
2. Файлы административной части копируются в правильные имена и подключают целевой модуль.
3. Автозагрузка регистрирует все классы и корректные пространства имён.
4. Меню, языковые файлы и административные ресурсы используют новые ключи.
5. События, cron и пользовательские точки входа используют новый ID.
6. Установка и удаление не затрагивают файлы других модулей.
7. Существующие профили и настройки не теряются при обновлении.
8. Остаточные старые идентификаторы объяснены или удалены после проверки зависимостей.

Удаляются только собственные рекламные, брендовые и копирайтные упоминания, на удаление которых у проекта есть права. Уведомления об авторстве, лицензиях и условиях распространения сторонних библиотек, а также обязательные заголовки исходных компонентов сохраняются. Перед публикацией проверяются лицензии самого исходного решения и всех включённых сторонних компонентов.

## Найденные внешние зависимости

- Демо-блокировка административного импортёра устранена. Совместимые функции оставлены в `install/demo.php`, но они больше не обращаются к API партнёрских обновлений или внешним сервисам лицензирования.
- Google Drive работает без внешнего OAuth callback для общедоступных файлов по прямым ссылкам. OAuth-обновление токена и авторизация через инфраструктуру прежнего разработчика удалены. Ссылки на закрытые папки Google Drive больше не поддерживаются; для импорта используйте общедоступную ссылку на отдельный файл.
- Ссылки на справку и видео в административной части ведут на `esolutions.su`. Пока они оставлены как внешняя документация исходного решения.
- Упоминание `CKitImportXml` в административном файле находится внутри закомментированного устаревшего блока; действующий запуск использует `CCodeMatrixImportXMLRunner`.

Не подменять внешние адреса вымышленными адресами CodeMatrix.

## Установщик и деинсталлятор

Установщик копирует ресурсы в системные каталоги Битрикс, а деинсталлятор удаляет namespaced-каталоги модуля и файлы, соответствующие шаблонам исходной папки установки. До тестирования на отдельной VM нельзя считать подтверждённым, что установка, обновление и удаление не затрагивают сторонние файлы.

Установщик использует `CopyDirFiles(..., true, true)` для копирования ресурсов в системные каталоги Битрикс; этот режим допускает перезапись совпадающих файлов. Деинсталлятор удаляет namespaced-каталоги модуля и файлы из плоских системных каталогов по соответствию файлам в `install/`. Требуется проверить на VM, что все целевые имена уникальны и удаляются только принадлежащие модулю файлы. `UnInstallDB()` вызывает только `UnRegisterModule()` и явно не удаляет настройки `COption`; это пока оставлено без изменений, чтобы не потерять данные при переустановке.
