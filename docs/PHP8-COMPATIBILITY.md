# Совместимость с PHP 8

## Целевая платформа

Цель проекта — PHP 8.0 и выше. Совместимость с конкретными версиями PHP 8.x должна подтверждаться автоматической проверкой и тестированием на соответствующем окружении.

## Что проверять в исходном коде

- короткие открывающие теги `<?` и зависимость от настройки `short_open_tag`;
- удалённые и устаревшие функции, включая `each()`;
- передачу некорректных аргументов внутренним функциям;
- обращения к несуществующим ключам и свойствам;
- динамические свойства классов;
- несовместимые сигнатуры методов при наследовании;
- обработку исключений и ошибок типов;
- функции работы со строками, регулярными выражениями, XML и файлами;
- использование `count()` с неподдерживаемыми типами;
- совместимость с актуальными версиями библиотек и API 1С-Битрикс.

## Требования к исправлениям

1. Не маскировать ошибки через подавление предупреждений.
2. Не менять бизнес-логику импорта без отдельного обоснования.
3. Для массивов использовать явные проверки и современные конструкции вместо удалённых функций.
4. Для nullable-значений явно определять допустимое поведение.
5. Не использовать динамические свойства; объявлять свойства классов явно.
6. Сохранять совместимость с поддерживаемыми версиями 1С-Битрикс.

## Критерии готовности

- Все PHP-файлы проходят `php -l` на целевой версии PHP.
- Статический анализ не выявляет критических ошибок.
- Установка и удаление проверены на тестовом сайте.
- Проверены импорт инфоблоков и Highload-блоков, продолжение прерванного импорта, журналирование и откат.
- Проверена работа cron и административных страниц.
- Регрессионные тесты не выявляют потери функциональности.

На текущем этапе эти критерии ещё не подтверждены.
