# CodeMatrix ImportXML

Модуль импорта и обновления каталога 1С-Битрикс из XML- и других поддерживаемых источников.

> **Статус разработки:** исходный код перенесён, идентификаторы CodeMatrix внедрены, синтаксис PHP проверен на версиях 8.0–8.4. Функциональное тестирование в окружении 1С-Битрикс ещё не завершено. До завершения проверки не устанавливайте модуль на рабочий сайт.

## Назначение

Модуль предназначен для автоматизации загрузки каталога и связанных данных в 1С-Битрикс. Исходная реализация содержит механизмы импорта элементов и разделов инфоблоков, работы с Highload-блоками, профилями импорта, расписанием/cron, журналированием и откатом операций. Фактический состав функций и поддерживаемых форматов будет уточнён по результатам аудита и тестирования перенесённой версии.

## Требования

- 1С-Битрикс: Управление сайтом с установленными необходимыми модулями платформы.
- PHP 8.0–8.4 — синтаксическая проверка выполняется автоматически через GitHub Actions.
- Набор расширений PHP определяется используемыми функциями импорта и будет зафиксирован после проверки зависимостей.
- Для работы с каталогом требуются соответствующие права на инфоблоки и, если используется, Highload-блоки.

## Установка

Инструкция по установке будет опубликована после интеграционной проверки установщика, регистрации модуля, административных файлов, ресурсов интерфейса и процедуры удаления. Не устанавливайте текущую ветку на рабочий сайт.

На текущем этапе ветка `feature/codematrix-port` является рабочей веткой переноса. Она не считается готовым релизом.

## Разработка

Основная ветка репозитория: `main`.

Рабочая ветка переноса: `feature/codematrix-port`.

Перед выпуском необходимо выполнить синтаксическую проверку всех PHP-файлов на PHP 8, проверить установку/удаление на тестовом экземпляре 1С-Битрикс и провести регрессионные испытания импорта на тестовых данных.
